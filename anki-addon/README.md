# αnki PWA Sync add-on

Windows Ankiを、αnki PWAの同期元として動作させる最小アドオンです。

## インストール

1. `alpha_anki_sync` フォルダーの中身をZIP化し、拡張子を `.ankiaddon` に変更します。
2. Ankiの「ツール → アドオン → ファイルからインストール」で読み込みます。
3. Ankiを再起動します。
4. 「ツール → αnki PWA URL設定」を開き、静的ホスティングへ公開したPWAのHTTPS URLを保存します。
5. 「ツール → αnki PWA ペアリング」を開きます。
6. iPhoneのホーム画面からαnkiを開き、「設定 → QRコードを読み取る」を押します。
7. カメラを許可してQRコードを読み取ると、同期先とペアリングコードが自動保存されます。

Windows Defender Firewallで確認された場合は、プライベートネットワークのみ許可してください。

## v0.1の境界

- 読み取るのは同期時点で復習対象になっているカードです。
- カード本文を変更するAPIはありません。
- 復習イベントのUUIDを保存し、再送されても二重適用しません。
- SafariのHTTPS→LAN内HTTP制限を避けるため、同期時のみWindowsのローカル中継画面を経由してPWAへ戻ります。
- オフライン中の実際の回答時刻はPWAに保持しますが、Ankiのスケジューラー遷移は同期時刻に適用します。過去時刻を完全再現する処理は今後の互換性検証対象です。
